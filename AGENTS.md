# Design skills - always use for frontend/UI work

This project has three design skills installed under `.claude/skills/`: `impeccable`, `emil-design-eng`, and `taste-skill`. For any frontend/UI task - new views, component work, redesigns, polish passes, animation, typography, layout, or visual review - invoke the matching skill(s) before writing UI code, even when working directly rather than through the `frontend-ui`/`design-system-architect` subagents. Don't rely solely on automatic description-matching triggering it; treat this as a standing rule for this repo.
